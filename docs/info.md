## How it works

The project consists of a 7-segment display system with 4 inputs and 8 outputs. The 4 inputs represent a 4-bit binary number, which is processed by the logic circuit to generate the corresponding output signals. The 8 outputs control the segments of the display (A, B, C, D, E, F, G) and the decimal point. These outputs turn the corresponding segments ON or OFF to display the correct decimal digit.

## How to test

To test the project, connect the 4 input switches and the 7-segment display to the circuit. Change the input switches to represent different binary numbers (0000 to 1111). Observe the display and verify that the corresponding digit appears correctly. Test all possible input combinations to check that the circuit works properly.
